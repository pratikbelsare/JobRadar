# JobRadar backlog

JobRadar matching and filtering are frozen as **matching v0.1** during integrated product
validation. The following evidence-backed improvements are intentionally deferred:

- Research Scientist context-qualified Stage-1 policy (Policy C)
- SDE / Software Engineer AI-ML classification
- prefixed recruiting-title normalization such as `Expression of Interest: Machine Learning Engineer`
- review possible source-level reposts/near-duplicates that have distinct stable source IDs
- low-ranked strong-target investigation
- skill normalization
- responsibility-score discrimination
- domain normalization
- native Bedrock Runtime and Titan migration after AWS Support restores account access

These items must not be introduced indirectly through Milestone 13/14 orchestration, API,
or UI work. Ranking changes should resume only as a separately reviewed evaluation milestone.
